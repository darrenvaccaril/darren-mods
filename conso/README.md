# conso

Barre affichée au-dessus de la zone de saisie de Claude Code : contexte utilisé (ex. 72k / 200k, 36 %), consommation sur la fenêtre de 5 heures et sur la semaine avec le délai avant remise à zéro, et coût de la session. Vert, orange à partir de 70 %, rouge à partir de 90 %.

Installation : ajouter la marketplace `darrenvaccaril/darren-mods` (Plugins → + → Ajouter depuis un dépôt), puis installer `conso`. Ou, dans une session Claude Code :

    /plugin marketplace add darrenvaccaril/darren-mods
    /plugin install conso@darren-mods

Puis ouvrir une nouvelle session.
